# Raksha Rajesh — Portfolio

A responsive, static black-and-gold portfolio website for GitHub Pages.

## Publish
1. Upload `index.html`, `README.md`, and the `assets` folder to the root of your public GitHub repository.
2. Add your current resume PDF to `assets/` using the exact filename `Raksha_Rajesh_Resume.pdf` so the Download Resume link works.
3. In repository Settings → Pages, choose Deploy from a branch, branch `main`, folder `/(root)`, then Save.

Before publishing, verify the email address, resume, experience statements, and contact links. Add your own LinkedIn profile URL in `index.html` before sharing.
